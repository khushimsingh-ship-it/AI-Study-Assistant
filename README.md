# AI Study Assistant

An AI-powered web application that helps students study, ask questions, create notes, generate quizzes, and track their learning progress.

## 🚀 Features

- 🤖 AI-powered study assistant
- 💬 Interactive AI chat
- 🧠 AI-generated quizzes
- 📊 Automatic quiz scoring
- 📈 Progress tracking
- 📝 Study notes management
- ⚙️ Student settings
- 💾 SQLite database
- 🔐 Environment-variable based API key protection
- 🌐 Flask web application

## 🛠️ Technologies Used

- Python
- Flask
- Google Gemini API
- HTML5
- CSS3
- JavaScript
- SQLite
- Git & GitHub
